# Features Summary

Source of truth for the current feature set. Row numbers (`#N`) are stable identifiers: other specs reference features by these numbers, so never renumber rows. Append new rows at the end.

| No. | Feature | Function | Purpose |
| --- | --- | --- | --- |
| 1 | Home Screen | Shows a focus space with a video background and a Start Focus button. | Creates a calm space to begin a focus session. |
| 2 | Zen Mode | Dims the page header and the start button to reduce distractions. | Helps users concentrate better. |
| 3 | Session Setup | Lets users enter a task name and choose the mode and duration of the session. | Personalizes a focus session before it starts. |
| 4 | Session Modes | Three options: Open (counts up), Target (counts down from a goal duration), and Pomodoro (cycles of focus and break phases that switch automatically). | Fits both free-form focus and sessions with a time goal. |
| 5 | Timer | Shows focus time; in Target mode, keeps showing time past the goal when the user wants to focus longer; in Pomodoro mode, shows the current phase and round progress. | Tracks the progress of the session. |
| 6 | Pause and Resume | Lets users pause, resume, or end the session. | Gives flexible control over focus time. |
| 7 | End Confirmation | Asks for confirmation before ending a session. | Prevents ending a session by accident. |
| 8 | Continue After Target | When the Target time runs out, users can end the session or keep focusing. | Avoids interrupting work when more time is needed. |
| 9 | Notifications | Sends a notification when a Target session reaches its goal, with a custom or default message; in Pomodoro mode, also notifies on each phase change; lets users preview the notification. | Reminds users when a focus goal is completed. |
| 10 | Focus History | Lists completed sessions with task, mode, time, and duration; Pomodoro sessions record focused time only and completed rounds. | Lets users look back at their focus activity. |
| 11 | Focus Statistics | Summarizes time for today, yesterday, and this week, plus session count, average duration, and longest session. | Helps users assess their focus habits. |
| 12 | Focus Chart | Shows focus time for the last 7 days as stacked bars broken down by mode (Open, Target, Pomodoro), with a legend. | Shows progress day by day and how focus time splits across modes. |
| 13 | Appearance Settings | Choose light, dark, or system theme; customize display style and colors. | Creates an experience that matches personal taste. |
| 14 | Default Session Settings | Choose the default mode and duration for new sessions, including Pomodoro focus, break, and round settings. | Saves time when starting each session. |
| 15 | Sound Settings | Adjust the default volume and remember the last-used environment. | Manages sound options for the focus experience. |
| 16 | Reset Settings | Restores appearance, session, and sound options to defaults without deleting history. | Makes it easy to return the app to its initial settings. |
| 17 | Shortcuts | F opens Session Setup, S opens Settings, H opens History, Z toggles Zen Mode; Space pauses and resumes the session; N skips the current Pomodoro phase. | Enables fast interaction without a mouse. |
| 18 | Session Save and Restore | Restores a running session after a reload or when the app is reopened. | Reduces the chance of losing focus progress. |
| 19 | Preference and History Persistence | Remembers settings, appearance, and focus history. | Keeps the personal experience between visits. |
| 20 | Quality and Platform | Supports phones, tablets, and desktops; keyboard navigation, accessibility, and reduced motion following device settings. | Delivers a convenient, easy-to-use experience across devices. |
